# `paper/` — the three-part write-up

The locality argument for $\mathrm{Tr}(\phi^3)$ tree amplitudes from cyclic hidden
zeros is currently distributed across three self-contained PDFs, each ~6–7 pp.
They are intended to be read in order, but each stands alone.

## Layout

```
paper/
├── README.md                              ← you are here
├── part1 1-zero asymptotic analysis/      Part I  — the 1-zero kill, through n = 9
├── part2 fat-zero generalization/         Part II — the k-zero kill (A/B/C criteria)
└── part3 step2 K-zero relations/          Part III — the Step-2 coefficient relations
```

## The three parts

| Part | Subfolder | Core claim |
|---|---|---|
| **I**   | [`part1 1-zero asymptotic analysis/`](./part1%201-zero%20asymptotic%20analysis/) | Locality from the cyclic hidden **1-zero** alone, proven through $n=9$ via Step-1 asymptotic kill + Step-2 Laurent cascade + the $n=9$ block rule. Asymptotic completeness $S(n)/T(n)\le 8/n+O(n^{-2})$. |
| **II**  | [`part2 fat-zero generalization/`](./part2%20fat-zero%20generalization/) | Promote the 1-zero to a **k-zero** (impose hidden-zero on $k$ consecutive boundaries). Rate-vector classification of admissible asymptotic limits gives the criteria $A$, $B$, $C$. Geometric shadow: non-crossing survival builds a $(k{+}2)$-gon over the length-$k$ enclosing chord in three flavours — via the special, the bare, or an internal column pair. |
| **III** | [`part3 step2 K-zero relations/`](./part3%20step2%20K-zero%20relations/) | Classification of **Step-2 coefficient relations** on each $k$-zero. Universal $m$-th order binomial trace $\sum_j(-1)^j a_{s^{m-j}b^j}=0$, plus per-column and per-offset relations. For $k\ge 2$ these include genuinely new identities like $a_{14,14}+a_{3n,3n}-a_{14,3n}=0$, unavailable from the 1-zero. |

## Building

Figures are generated by matplotlib scripts in each subfolder's `figures/`; the
papers are compiled with [tectonic](https://tectonic-typesetting.github.io/).

```bash
cd "paper/part2 fat-zero generalization/"   && python3 figures/make_figures.py && tectonic fat_zero_part2.tex
cd "paper/part3 step2 K-zero relations/"    && python3 figures/make_figures.py && tectonic step2_part3.tex
```

(Part I currently lives as a built PDF only; its source is staged separately.)

Part II also ships a sympy stress-test suite at
`paper/part2 fat-zero generalization/tests/stress_tests.py` that symbolically
verifies every load-bearing claim of Parts II and III. See its README for the
catalogue (telescoping lemma, chord-rate table, Prop 1 over 17,602 multisets,
binomial trace, per-column and offset relations, triangulation escape over 400
Catalan-many triangulations).

## Naming convention

- Subfolder names start with `partN ` so they sort in reading order.
- Each subfolder has its own README pointing into the PDF and source.
- Older drafts and superseded approaches live in `../old stuff/paper-older-works/`,
  never in here.
